# Security policy

## Reporting a vulnerability

Please do not publish exploitable security details, credentials, session data, or private information in a public issue.

Use GitHub's private vulnerability reporting feature for this repository if it is enabled. If private reporting is unavailable, contact the repository maintainer privately through a verified GitHub contact method and include steps to reproduce, the affected component, and potential impact.

Do not include real passwords, API keys, access tokens, or personal data in reports or commits.

## Scope

Security-sensitive areas include authentication, permissions, plugin execution, external content and iframe handling, local storage, service workers, and any code that handles user-supplied HTML or JavaScript.
