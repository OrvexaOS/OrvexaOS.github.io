# Changelog

All notable changes to OrvexaOS are documented here.

## [Unreleased]

- Continue migrating app source templates into the live app runtime.
- Improve automated validation, security checks, and release workflows.
- Preserve the existing boot flow and local browser data behavior.

## [History]

- Added a browser-based desktop shell, local productivity apps, app store and plugin runtime.
- Added responsive desktop layouts, customization controls, local backup and restore, and installable web app support.
- Added GitHub Actions validation, app registry auditing, issue templates, contribution guidance, and dependency update configuration.
